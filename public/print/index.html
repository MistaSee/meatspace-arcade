🪙 Coin stickers

Each sticker is 38 mm across and fits the recess in the 3D-printed coin. Each one opens its own numbered coin, so the Hall shows which coin a score came from.

  1. Print at 100% / actual size, not "fit to page".
  2. Cut round the dashed line and stick it in the coin's recess.
  3. Scan to play. The codes point at …, so phones must be on the same Wi-Fi.
